# Code of Conduct

## Standards
We are committed to providing a welcoming, respectful, and harassment-free environment for all contributors, regardless of experience, background, or identity.

## Expectations
- Focus on technical rigor, constructive feedback, and mutual respect.
- Address engineering disagreements with empirical data, tests, and specifications.
- Protect project integrity and community collaboration.

## Reporting
Concerns may be reported privately to project maintainers via GitHub security reporting or private maintainer channels.
