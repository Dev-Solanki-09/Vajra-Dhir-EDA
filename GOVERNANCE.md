# Project Governance

Vajra-Dhīr EDA is an open-source technical initiative guided by transparent RFC decision-making and meritocratic code review.

## Decision Model
- **Architectural Changes:** Major schema, kernel, or protocol modifications require an Architecture RFC with review from designated domain maintainers.
- **Fail-Closed Verification:** Automated tests and compliance gates take precedence over opinion. Code must satisfy deterministic verification before merging.
- **Maintainers:** Maintainership is granted based on consistent technical contributions, review rigor, and adherence to the project constitution.
