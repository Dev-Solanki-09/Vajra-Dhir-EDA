# Keyboard & Mouse Shortcuts Reference

## Viewport Navigation (All 2D & 3D Canvases)
| Shortcut | Action |
|---|---|
| `Mouse Wheel` | Zoom centered on cursor |
| `Space + Left Drag` or `Middle Drag` | Smooth pan |
| `Right Click` (stationary) | Context menu |
| `0` / `F` / `Home` | Zoom to fit active design |

## Schematic & PCB Editing
| Shortcut | Action |
|---|---|
| `G` | Toggle Drag / Move tool |
| `R` | Rotate selected part +90° |
| `Shift+F` | Flip footprint side (`F.Cu <-> B.Cu`) |
| `L` | Lock / Unlock selected part |
| `X` | Route 45° trace |
| `V` | Place via (flips active copper layer mid-route) |
| `B` | Refill copper pour zones |
| `Alt + Hover` | Redline clearance & delta measurement |
| `Delete` / `Backspace` | Delete unlocked selection |

## Application & Workspaces
| Shortcut | Action |
|---|---|
| `Ctrl+S` | Save revision snapshot |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo |
| `Ctrl+K` | Command Palette |
| `Ctrl+,` | Preferences / Settings |
| ``Ctrl+` `` | Toggle Bottom Utility Drawer |
| `F1` | Offline Help Center & Guides |
| `F5` / `F6` / `F7` | Run Verification / SPICE Sim / Co-Sim |
